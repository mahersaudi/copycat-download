# Copycat

**لعبة اختباء بين الزحمة:** إنت واحد من الناس بالساحة. الزحمة فجأة بتوقف أو بتركض أو بترقص — ولازم تقلّدهن بالوقت،
وإلا الباحث بيلاحظ الوحيد يلي تحرّك غلط.

*Blend into the crowd. Move wrong and you're caught.*

## التشغيل · Running it

1. فك ضغط الملف لمجلد، وشغّل `Copycat.exe` من جوّا المجلد (مش من جوّا الـ zip).
2. إذا طلعت رسالة **"Windows protected your PC"**: اكبس **More info** ← **Run anyway**. اللعبة مش موقّعة رقمياً، لهيك ويندوز بيسأل.

*Unzip the whole folder and run `Copycat.exe` from inside it. If Windows shows "Windows protected your PC", click
**More info → Run anyway** — the game isn't code-signed.*

## اللعب مع الأصحاب · Playing with friends

**كلكن لازم يكون عندكن نفس النسخة.** · *Everyone needs the same version.*

| | |
|---|---|
| **أونلاين** (كل واحد ببيته) | واحد بيكبس **استضف أونلاين** وبيبعت الكود، والباقي بيكتبوا الكود وبيكبسوا **انضم بكود**. ما بدها فتح منافذ. |
| **Online** (anywhere) | One player presses **HOST ONLINE** and shares the code; the others type it and press **JOIN CODE**. No port forwarding. |
| **واي فاي** (نفس الشبكة) | واحد بيكبس **استضف على الواي فاي** والباقي **انضم**. إذا سأل جدار الحماية، اكبس **Allow**. |
| **Wi-Fi** (same network) | One player presses **HOST WI-FI**, the others press **JOIN**. Allow the game through the Windows firewall if asked. |

لحتى 8 لاعبين. أو العب لحالك ضد الذكاء الاصطناعي. · *Up to 8 players, or play solo against the AI.*

## الأزرار · Controls

| | |
|---|---|
| حركة · Move | `W A S D` |
| قعود · Sit | `C` |
| قلّد الزحمة · Copy the crowd | `1` حكي/chat · `2` تأشير/point · `3` رقص/dance |
| قدرات · Abilities | `Q` `E` `R` · `SHIFT` dash |
| الباحث · As the Seeker | `F` اتهام/accuse · `Q` `E` `R` `T` أدوات/tools · `1`–`6` أوامر/commands |
| إيقاف · Pause | `ESC` |

كل الأزرار بتتغيّر من الإعدادات. اللعبة بالعربي والإنكليزي. · *Every key can be changed in Settings. English and Arabic.*
